# Local Bootstrap

## Requirements

- PHP 8.3+
- Composer
- Node.js and npm
- MySQL 8+
- Redis
- Git

## Create the Laravel application

Use the official Laravel React starter kit for the initial application scaffold. Current official starter kits use Laravel 13, React 19, TypeScript, Inertia 3 and Vite. The starter kit also provides authentication, settings and GitHub Actions scaffolding.

From the parent directory:

```bash
composer global require laravel/installer
laravel new messenger-crm
```

Choose the React starter kit when prompted. Use Laravel's built-in authentication rather than an external auth provider for the initial build.

Then install dependencies and start the application using the commands generated by the starter kit:

```bash
cd messenger-crm
npm install
npm run build
php artisan migrate
php artisan serve
```

For local development, configure MySQL and Redis in `.env`. Do not commit `.env` or provider credentials.

## Repository setup

The GitHub repository is:

`mhsani/messenger-crm`

The initial architecture documentation was committed before application scaffolding so the codebase can be checked against the frozen architecture.

## Important

Do not run a second Laravel project generator inside this repository if the repository already contains a Laravel scaffold. Merge the generated scaffold into the repository once, then build features incrementally.

## First implementation milestone

After the scaffold exists, implement in this order:

1. Base migrations and models.
2. Organization/tenant context.
3. RBAC.
4. Provider contracts.
5. Meta integration skeleton.
6. Webhook persistence endpoint.
7. Webhook processing job.
8. Conversation/message domain.
9. Inbox API and React page.

## Verification

Before every milestone:

```bash
php artisan test
vendor/bin/pint --test
npm run build
```

If static analysis is enabled in the generated starter kit, run it as part of CI as well.
